# UI System Designer

Esta skill atua em praticamente TODAS as páginas.

**Regra Principal:**
- **NUNCA** cria funcionalidades lógicas de back-end.
- O foco é **APENAS** melhorar a estética e estrutura visual da interface.

**Inspirações de Excelência Visual:**
- Stripe
- Linear
- Vercel
- Arc Browser
- Raycast
- Notion

**Pontos de Atenção Contínua:**
- Alinhamento matemático e consistência.
- Spacing (Respiro entre os elementos).
- Grid (Sistemas estruturados e harmoniosos).
- Tipografia (Tamanhos e pesos premium).
- Contraste (Legibilidade impecável).
- Hierarquia (O que o usuário deve ver primeiro, segundo e terceiro).
