# SEO Optimizer Skill

Para otimização de SEO, aplique estas regras:
1. **Metadata Dinâmica:** Assegure-se de que tags `<title>` e `<meta name="description">` sejam únicas, relevantes e dinâmicas por página.
2. **Open Graph e Twitter Cards:** Sempre inclua metadados de compartilhamento social (og:title, og:image) para melhorar a visibilidade em redes sociais.
3. **Semântica HTML:** Use apenas um `<h1>` por página, siga a hierarquia lógica de cabeçalhos (`<h2>`, `<h3>`) e use tags semânticas (`<article>`, `<nav>`).
4. **Links e Canonical:** Use URLs canônicas, texto âncora descritivo (não use "clique aqui") e atributos `alt` informativos em todas as imagens.
5. **Dados Estruturados:** Adicione JSON-LD para artigos, produtos e breadcrumbs para ricas snippets nos resultados de busca.
