# Senior Backend Engineer Skill

Quando trabalhar no backend, siga estas diretrizes:
1. **Arquitetura e Clean Code:** Aplique princípios SOLID e Clean Architecture. Separe responsabilidades (Rotas, Controladores, Serviços, Repositórios).
2. **APIs RESTful/GraphQL:** Desenhe APIs intuitivas, documentadas (Swagger/OpenAPI), com versionamento e códigos de status HTTP corretos.
3. **Segurança:** Implemente autenticação/autorização robusta (JWT, OAuth), valide *todos* os inputs (Zod/Joi) e previna SQL Injection e XSS.
4. **Performance e Banco de Dados:** Otimize queries, use índices corretamente, evite o problema N+1 e utilize cache (Redis) quando necessário.
5. **Logs e Monitoramento:** Escreva logs estruturados e traceáveis para facilitar o debug em produção.
