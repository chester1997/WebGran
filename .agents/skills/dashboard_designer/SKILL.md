# Dashboard Designer

O mestre da organização da informação complexa. Esta skill é perfeita para a estruturação do aplicativo central do projeto.

**Referências para Clonar a Excelência:**
- Stripe Dashboard (Simplicidade e foco)
- Payflow
- Linear (Precisão, estética dark mode e produtividade de atalhos)
- Vercel (Minimalismo)
- ClickUp
- Arc Browser (Organização espacial)

**Compreensão Profunda de:**
- **Workspace:** Visão geral da área de trabalho do usuário.
- **Sidebar:** Estruturação lógica e responsiva do menu lateral.
- **Surfaces:** Camadas (z-index), profundidade, cartões e separação de áreas através de backgrounds.
- **Cards & Widgets:** Visualização isolada de métricas e ações.
- **Grids Complexos:** Layouts de painéis para não afogar o usuário em informação, mesmo quando ela é densa.
