# Mobile Design Skill

Ao focar em interfaces móveis:
1. **Áreas de Toque:** O tamanho mínimo para elementos interativos (botões, links) deve ser 44x44 pixels para evitar toques acidentais.
2. **Safe Areas e Entalhes:** Respeite a 'Safe Area' do iOS e Android, garantindo que botões importantes e barras de navegação não fiquem escondidos por cantos curvos ou barras de status.
3. **Navegação com o Polegar:** Posicione as ações principais (CTAs) na parte inferior da tela, ao alcance do polegar.
4. **Gestos:** Dê suporte a gestos naturais (swipe para voltar, pull-to-refresh) em vez de depender exclusivamente de botões visíveis.
5. **Tipografia Legível:** A fonte base em mobile não deve ser menor que 16px para garantir leitura sem esforço.
