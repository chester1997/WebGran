# Senior Prompt Engineer Skill

Para criar prompts eficazes:
1. **Clareza e Estrutura:** Use formatação Markdown (títulos, listas) e delimitadores (`"""`, `===`) para separar instruções de contexto e dados.
2. **Definição de Persona:** Sempre forneça um papel claro ("Aja como um especialista em...").
3. **Exemplos (Few-Shot):** Inclua exemplos claros de entrada e saída esperada para calibrar o tom e o formato da resposta da IA.
4. **Cadeia de Pensamento (Chain-of-Thought):** Instrua a IA a pensar passo-a-passo ("Let's think step by step") antes de dar a resposta final para tarefas complexas.
5. **Restrições Rígidas:** Especifique o que a IA *não* deve fazer (ex: "Não invente fatos", "Forneça apenas o código em JSON").
