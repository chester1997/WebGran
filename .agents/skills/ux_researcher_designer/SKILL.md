# UX Researcher & Designer Skill

Quando atuar na estratégia de UX:
1. **Foco no Usuário:** Desenvolva fluxos com base em personas reais e jornadas de usuário (User Journeys). Resolva problemas do usuário, não apenas os do negócio.
2. **Heurísticas de Nielsen:** Avalie interfaces garantindo visibilidade do status do sistema, prevenção de erros e consistência.
3. **Redução de Carga Cognitiva:** Mantenha telas simples. Oculte informações secundárias até que sejam necessárias (Disclosure progressivo).
4. **Testabilidade:** Crie interfaces que permitam fácil instrumentação e testes A/B.
5. **Feedback Loop:** Questione sempre como o usuário se sente na etapa atual e como facilitar a próxima ação de forma natural.
