# UI Design System Skill

Quando trabalhar com Design Systems, siga estas diretrizes:
1. **Tokens de Design:** Defina variáveis absolutas (Cores, Espaçamentos, Tipografia) e Tokens Semânticos (ex: `--color-primary-button`).
2. **Componentes Isolados:** Crie componentes independentes, agnósticos de contexto de negócio, totalmente reutilizáveis e com API clara (Props claras).
3. **Variantes e Estados:** Mapeie todos os estados de um componente (Default, Hover, Active, Disabled, Error, Loading).
4. **Documentação:** Documente o uso de cada componente (usando ferramentas como Storybook se aplicável) e as regras de composição.
